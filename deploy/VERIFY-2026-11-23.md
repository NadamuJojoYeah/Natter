## 2. 验证

### 2.1 服务活着

```bash
systemctl is-active natter
```

```
active
```

### 2.2 没在崩溃循环（关键）

```bash
sudo journalctl -u natter --since "2 min ago" --no-pager | grep -c "Started"
```

```
1
```

**大于 1 就是还在循环重启，停下告诉我。**

### 2.3 插件状态

```bash
curl -s http://127.0.0.1:5099/health | jq '{status, activated: .plugins.activated, failed: .plugins.failed}'
```

```
{
  "status": "plugins-failed",
  "activated": 7,
  "failed": 3
}
```

`failed` 应该是 **3**（dingtalk / spark / prompt.library 三个没配凭证的）。

**如果是 4，说明 webconsole 还没好**，做 2.4。

### 2.4 审计目录权限（仅当 2.3 是 4 时执行）

```bash
sudo chown -R natter:natter /opt/natter/plugins/natter.tool.admin.webconsole/audit
sudo chmod 0750 /opt/natter/plugins/natter.tool.admin.webconsole/audit
sudo systemctl restart natter.service
```

再跑一次 2.3，`failed` 应变回 3。

### 2.5 Discord 连接

```bash
curl -s http://127.0.0.1:5099/health | jq -r '.upstreams[] | "\(.source) connected=\(.connected) sendFailures=\(.sendFailures)"'
```

```
discord:discord:... connected=true sendFailures=0
```

## 3. 功能测试（在 Discord 里发）

### 3.1 分片修复：emoji

发给 bot：

```
请原样重复下面这段，不要省略：
👨‍👩‍👧‍👦👨‍👩‍👧‍👦👨‍👩‍👧‍👦👨‍👩‍👧‍👦👨‍👩‍👧‍👦🇨🇳🇨🇳🇨🇳🇨🇳🇨🇳
```

**通过**：10 个 emoji 一个不少地回来。

**失败**：少字、报错、或消息根本没到。

### 3.2 分片修复：代码块

发给 bot：

```
请输出一个 150 行的 C# 代码块，每行都是 Console.WriteLine("line NNN");
```

**通过**：每一条消息都是**完整的代码块**（有自己的 ``` 开头和结尾），Discord 里显示为多个独立代码框。

**失败**：某条显示成纯文本、或开头/结尾缺 ``` 。

### 3.3 会话控制台

```bash
TOKEN=$(sudo grep CONVERSATION_CONSOLE_TOKEN /etc/natter/live.env | cut -d= -f2-)
curl -s -H "Authorization: Bearer $TOKEN" "http://127.0.0.1:5091/api/conversations?limit=3" | jq '.items | length'
```

**通过**：输出 ≥ 1 的数字。

**输出 0 或报错**：告诉我，这条可能是真 bug。

浏览器打开 `http://127.0.0.1:5091`，输入 token，看能不能列出会话。

### 3.4 WebConsole

```bash
curl -s -o /dev/null -w "%{http_code} %{content_type}\n" http://127.0.0.1:5090/app.js
```

```
200 text/javascript; charset=utf-8
```

浏览器打开 `http://127.0.0.1:5090`，输 token，看页面能不能加载（时间轴、折叠、诊断包按钮）。
